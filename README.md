## 📖 About

This portfolio website showcases my professional journey, projects, skills, and experience in data analytics and machine learning. The site features a modern, responsive design with dark/light theme support and interactive elements.

---

## ✨ Features

- **Responsive Design** – Optimized for desktop, tablet, and mobile devices  
- **Dark/Light Theme** – Toggle between dark and light themes with localStorage persistence  
- **Project Filtering** – Filter projects by technology tags  
- **Contact Form** – Functional contact form with Formspree integration  
- **Calendly Integration** – Schedule meetings directly through the Contact page  
- **Professional Layout** – Clean, modern, recruiter-friendly design  
- **SEO Optimized** – Meta tags and semantic HTML for better search visibility  
- **Fast Loading** – Pure static files for optimal performance  

---

## 🛠 Technologies Used

### Frontend
- **HTML5:** – Semantic markup and structure  
- **CSS3:** – Modern styling with CSS variables and Grid/Flexbox  
- **Vanilla JavaScript:** – No frameworks, pure JS for interactivity 
- **SVG Icons:** – Scalable vector icons for UI elements  

### Tools & Services
- **GitHub Pages:** - Static site hosting
- **Formspree:** - Contact form backend
- **Calendly:** - Meeting scheduling
- **Google Fonts:** - Typography (Inter font)
